# AVGO 기능 개념도 이미지 (AI 생성)

기업 구조도의 각 제품군에 붙는 **기능 설명 개념도**. 아래 파일명으로 넣으면
해당 제품군 카드에 자동 표시된다(없으면 조용히 생략). 파일은
`data/companies/AVGO.json` 의 `segments[].families[].image` 가 가리킨다.

## 권장 사양
- 가로형, **16:9 정도(예: 1280×720)**, 다크 배경(대시보드가 다크 테마)
- **글자 최소화**(AI 이미지의 텍스트는 깨지기 쉬움) — 아이콘·도형 위주의 개념도
- 플랫/아이소메트릭 일러스트, 한 장에 하나의 개념만 명확하게

## 필요한 4장

| 파일명 | 제품군 | 그려야 할 장면 |
|---|---|---|
| `switch.png` | AI 네트워킹(스위치) | 중앙의 네트워크 **스위치 칩 1개**가 사방의 **수십 개 GPU/서버**를 광케이블로 연결해 하나로 묶는 개념도 (허브-스포크) |
| `optical.png` | 광 인터커넥트 | **칩에서 나온 전기 신호가 '빛'으로 바뀌어 광섬유를 타고 멀리 뻗는** 장면 (전기→광 변환, 길게 뻗는 광선) |
| `xpu.png` | 맞춤형 AI 가속기(XPU) | **고객(클라우드 로고 느낌의 구름 3개) → 브로드컴 설계(청사진) → 완성된 칩 패키지**로 이어지는 코디자인 흐름 |
| `vmware.png` | VMware | **여러 물리 서버(랙) 무더기가 하나의 '구름(사설 클라우드)'으로 추상화**되는 장면 |

> 다른 기업도 같은 방식: `data/companies/images/<TICKER>/<name>.png` 에 넣고
> 그 기업 JSON 의 family `image` 에 경로를 적으면 된다.
