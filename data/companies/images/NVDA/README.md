# NVDA 기능 개념도 이미지 (AI 생성)

`data/companies/NVDA.json` 의 family `image` 가 가리키는 기능 개념도.
파일명을 맞춰 이 폴더에 넣으면 해당 제품군 카드에 자동 표시된다(없으면 생략).

## 권장 사양
- 가로형, **16:9 정도(예: 1280×720)**, 다크 배경(대시보드가 다크 테마)
- 엔비디아 톤(초록 #76b900) 살짝 섞으면 좋음, **글자 최소화**
- 플랫/아이소메트릭 일러스트, 한 장에 하나의 개념만 명확하게

## 필요한 4장

| 파일명 | 제품군 | 그려야 할 장면 |
|---|---|---|
| `gpu.webp` | AI 가속기 (GPU) | 하나의 **거대한 GPU 칩** 안에서 **수천 개의 작은 연산 코어가 병렬로 빛나며 동시에 계산**하는 개념도 (CPU의 직렬 vs GPU의 병렬 대비 느낌) |
| `nvlink.webp` | 데이터센터 네트워킹 | **여러 GPU가 NVLink/NVSwitch로 촘촘히 직결**되어 하나의 거대한 GPU처럼 묶이는 개념도 (브로드컴의 '스위치 허브'와 대비되는 격자형 직결) |
| `rack.webp` | AI 시스템 | **하나의 거대한 랙 시스템(GB200 NVL72)** 이 'AI 공장'처럼 표현 — 수십 개 GPU+네트워킹+냉각이 한 캐비닛에 통합된 모습 |
| `cuda.webp` | AI 소프트웨어·CUDA | **GPU 위에 소프트웨어 스택(CUDA·라이브러리·개발자 생태계)이 층층이 쌓여** 칩을 감싸는 개념도 — '해자(moat)' 느낌, 다른 칩은 못 들어오는 |

> 이미지가 없어도 카드는 쉬운 설명·문제→해결·제품 목록으로 정상 작동한다.
