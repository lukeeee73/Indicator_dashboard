# `data/eval/` — 자동판정 모델 백테스트 결과

`scripts/backtest.py` / `scripts/compare_models.py` 가 생성하는 채점 결과.
정답지는 `data/labels/` (NBER 침체 + 사전 등록 규칙 기반 인플레 episode).

## 파일

- `baseline.json` — 베이스라인(A) 단독 채점 + per-episode 상세
- `baseline_timeline.json` — 베이스라인의 월별 점수/라벨 시계열
- `comparison.json` — 모델 A~H 전체 비교

## 모델 요약 (1980-01 ~ 2026-05, 발표 지연 시뮬레이션 포함)

| 모델 | 침체: 적중 / 중위선행 / FPR / flips | 인플레: 적중 / 중위선행 / FPR / flips |
|---|---|---|
| A baseline (레벨 백분위 평균)   | 4/4 · +15m · 21.6% · 0.82 | 3/3 · +2m · 12.1% · 0.82 |
| B diff-aware (레벨60+방향40)    | 4/4 · +15m · 10.9% · 1.18 | 3/3 · +5m · 16.8% · 0.82 |
| C lead-weighted (선행 가중)     | 4/4 · +16m · 20.5% · 0.73 | 3/3 · +1m ·  7.7% · 0.77 |
| D C+smooth+hysteresis           | 4/4 · +14m · 28.9% · 0.26 | 3/3 · +0m · 10.1% · 0.34 |
| E cycle-relative (8y)           | 4/4 · +18m · 10.7% · 1.10 | 2/3 · −5m · 20.1% · 1.16 |
| F E(성장)+C(인플레)             | 4/4 · +18m · 10.7% · 1.10 | 3/3 · +1m ·  7.7% · 0.77 |
| G F+smooth+hysteresis           | 4/4 · +16m · 21.0% · 0.28 | 3/3 · +0m · 10.1% · 0.34 |
| **H F+EWMA only (운영 채택)**   | **4/4 · +16m · 7.7% · 0.54** | **3/3 · +0m · 5.9% · 0.52** |

## 채택 근거 (H)

- F 는 베이스라인 A 를 거의 모든 면에서 지배했지만 라벨 깜빡임(flips/yr 1.10)이 약점.
- G(히스테리시스 추가)는 깜빡임을 0.28 로 줄였지만 "이탈 50" 임계가 라벨을 episode
  종료 후에도 오래 붙잡아 FPR 이 21.0% 로 되돌아감 — 히스테리시스가 FPR 의 주범.
- H(EWMA 평활만, 라벨은 60/40 그대로)는 절제(ablation) 실험으로 분리해 본 결과
  **모든 지표에서 A 를 지배**: FPR 을 1/3(성장)~1/2(인플레)로 줄이고 깜빡임도
  개선하면서 선행성(+16m / +0m)을 유지.
- 단 하나의 trade-off: 인플레 중위 선행이 A 의 +2m → +0m (동월 포착). 평활의
  본질적 비용으로 수용.

H 의 산식과 하이퍼파라미터는 `scripts/analyze.py` (프로덕션) 에 정의되어 있고,
`scripts/compare_models.py` 가 같은 코드를 import 해서 백테스트한다 (단일 출처).
모든 하이퍼파라미터는 사전 등록 — 백테스트 결과를 보고 사후 조정하지 않는다.

## 한계 (정직 기록)

- 발표 지연(release lag)만 시뮬레이션. 데이터 사후 개정(revision)은 미반영 —
  엄밀한 vintage 백테스트는 ALFRED API 필요.
- 평가 가능한 침체 episode 가 4개(1990·2001·2008·2020), 인플레 3개뿐이라
  통계적 검정력이 낮다. 모델 간 차이는 "지배 관계" 수준에서만 해석할 것.
- 1980 이전 episode 는 지표 history 부족으로 검열(censored) 처리.
